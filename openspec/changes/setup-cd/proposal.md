# Proposal

## Why

[PRD-31](https://linear.app/po-sostavu/issue/PRD-31). CI проверяет четыре Docker-образа, но удаляет их вместе с runner. Нужна доставка этих же образов на подготовленный VPS после отдельного подтверждения выкладки.

## What Changes

- Передавать проверенные образы через Actions Artifacts, измерить размер и время передачи
- Добавить `cd.yml`: публикация публичных пакетов GHCR после успешного push CI в main, затем защищённый Environment production
- Подготовить отдельный production Compose, ограниченный серверный обработчик и blue-green с общей PostgreSQL
- Проверять конфигурации и сценарии отказов локально и в CI
- Первый этап завершён с выключенными публикацией и деплоем. Следующий этап по поручению владельца — подготовить первый тестовый выпуск и включение CD. Выкладка требует подтверждения конкретного выпуска через Environment production
- Добавить явный тестовый режим без подтверждения восстановления внешних резервных копий. Локальная копия перед миграцией остаётся обязательной, рабочий режим сохраняет прежнее требование восстановления

## Capabilities

### New Capabilities

- `release-delivery`: доставка проверенных образов, переключение выпуска и сохранение данных и старых файлов PWA

### Modified Capabilities

Нет

## Impact

Workflows, инфраструктура и регламент выпуска. Продуктовые PWA и API не меняются. Инструменты доставки написаны на Go со стандартной библиотекой в отдельном модуле tools/delivery. Сервер получает готовый бинарник без дополнительных runtime-зависимостей. Локальный Compose сохраняется.
