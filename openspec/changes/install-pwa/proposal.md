# Proposal

## Why

[PRD-33](https://linear.app/po-sostavu/issue/PRD-33). Каркас уже поставляет manifest, иконки и service worker, но не объясняет пользователю, как установить приложение. Кнопка в шапке даст доступ к установке на телефоне и компьютере с учётом возможностей браузера.

## What Changes

- Добавить кнопку «Установить» в шапку приложения
- По нажатию открывать системное окно установки, когда браузер предоставляет эту возможность
- В остальных случаях показывать короткую инструкцию для устройства и браузера
- Скрывать кнопку в установленном окне PWA, после подтверждённой установки и при доступном положительном ответе браузера об установленной PWA
- Обрабатывать отмену, ошибку и повторные нажатия без автоматического показа системного окна
- Проверить сценарии установки, адаптивность и доступность, выпустить изменение в версии `0.2.0`

В обычной вкладке не каждый браузер позволяет определить установленность. Отсутствие такого API не считается доказательством, что приложение не установлено. Постоянный локальный флаг установки не добавляется.

## Capabilities

### New Capabilities

- `pwa-installation`: доступ к установке PWA, инструкции для браузеров без программного вызова установки и скрытие действия при подтверждённой установленности

### Modified Capabilities

Нет. Основные `openspec/specs` пока пусты. Изменение дополняет оболочку из `bootstrap-pwa`, не меняя её политику обновления и кэширования.

## Impact

Затронуты `apps/pwa/src/features/install-app`, шапка в `app/layouts`, manifest в `vite.config.ts`, документация PWA и описание выпуска. Новых зависимостей npm нет. HTTP API, БД, миграции, серверные секреты и политика service worker не меняются. Выпуск проходит существующий Git Flow и CI/CD.
