# Spec Delta

## Purpose

Пользователь может установить «ПоСоставу» с телефона или компьютера через действие в шапке. Приложение учитывает возможности браузера и не обещает автоматическую установку там, где она недоступна.

## ADDED Requirements

### Requirement: Установка по действию пользователя

Приложение SHALL показывать кнопку «Установить» в шапке, пока установленность не подтверждена доступными браузерными сигналами. Если браузер предоставляет системное окно установки, приложение SHALL открывать его только после нажатия кнопки и не более одного раза для одного разрешения браузера.

#### Scenario: Системная установка доступна

- **WHEN** браузер разрешил программный показ установки и пользователь нажимает «Установить»
- **THEN** открывается системное окно, повторное нажатие во время его обработки не открывает второе окно

#### Scenario: Установка не запрашивалась

- **WHEN** пользователь открывает приложение или переходит между его разделами
- **THEN** системное окно установки и инструкция не открываются автоматически

### Requirement: Отмена и ошибка установки

Приложение SHALL сохранять возможность пользоваться основным интерфейсом после отмены или ошибки установки. Использованное разрешение браузера SHALL NOT запускаться повторно. Ошибка SHALL сопровождаться понятным сообщением и доступом к ручной инструкции.

#### Scenario: Пользователь отменил установку

- **WHEN** пользователь закрывает системное окно без установки
- **THEN** ожидание завершается, приложение не считается установленным, следующее нажатие использует новое разрешение браузера либо открывает инструкцию

#### Scenario: Браузер отклонил вызов

- **WHEN** вызов системной установки завершился ошибкой
- **THEN** ожидание завершается, пользователь видит сообщение об ошибке и может открыть инструкцию, навигация остаётся рабочей

### Requirement: Инструкции для ручной установки

Если системный вызов недоступен, приложение SHALL по нажатию показывать короткую инструкцию для платформы. Инструкция SHALL описывать действия в браузере, а при отсутствии нужного пункта предлагать совместимый браузер. Она SHALL NOT сообщать об успешной установке без подтверждения.

#### Scenario: iPhone или iPad

- **WHEN** пользователь нажимает «Установить» в обычной вкладке iOS или iPadOS без доступного системного вызова
- **THEN** диалог объясняет добавление через «Поделиться» и «На экран Домой», с запасным вариантом открытия в Safari при отсутствии пункта

#### Scenario: Компьютер или Android

- **WHEN** пользователь нажимает кнопку без доступного системного вызова на компьютере или Android
- **THEN** диалог показывает подходящий ручной способ и не обещает поддержку установки всеми версиями браузеров

### Requirement: Скрытие при подтверждённой установленности

Кнопка SHALL быть скрыта в установленном окне приложения и после браузерного подтверждения установки. Положительный ответ доступной проверки установленности SHALL скрывать кнопку только для собственной PWA. Недоступность проверки, пустой результат и ошибка SHALL NOT означать установленность. Постоянный флаг установленности в клиентском хранилище SHALL NOT использоваться.

#### Scenario: Приложение открыто с устройства

- **WHEN** пользователь запускает PWA в отдельном установленном окне
- **THEN** кнопка установки не отображается

#### Scenario: Установка завершилась в текущей сессии

- **WHEN** браузер подтверждает завершение установки
- **THEN** кнопка и открытая инструкция скрываются, поздний ответ предыдущей асинхронной проверки не возвращает их

#### Scenario: Проверка обычной вкладки

- **WHEN** браузер достоверно сообщает об установленной собственной PWA
- **THEN** кнопка скрывается, сведения о другом приложении не влияют на её видимость

#### Scenario: Установленность неизвестна

- **WHEN** браузер не умеет проверять установленность, возвращает пустой результат или ошибку
- **THEN** основное приложение продолжает работать, кнопка остаётся доступной при отсутствии других подтверждений установки

### Requirement: Доступность на узком экране

Кнопка SHALL иметь понятное доступное имя и область нажатия не менее 44 × 44 px. Шапка и инструкция SHALL помещаться на экране шириной 320 px без горизонтальной прокрутки. Диалог SHALL поддерживать управление клавиатурой, закрытие Escape и возврат фокуса к доступному элементу интерфейса.

#### Scenario: Телефон и клавиатура

- **WHEN** пользователь открывает инструкцию на экране шириной 320 px либо с помощью клавиатуры
- **THEN** содержимое остаётся читаемым, фокус находится внутри диалога, его можно закрыть без мыши и продолжить работу
