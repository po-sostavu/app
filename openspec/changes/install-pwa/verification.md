# Проверка установки PWA

8 ноября 2026 года, PRD-33. Проверена production-сборка реализации `6395dfd` через локальный Vite preview. Новых зависимостей нет.

[Выпуск 0.2.0](../../../docs/releases/0.2.0.md) опубликован и после подтверждения владельца развёрнут на VPS. Вторая попытка [CD](https://github.com/po-sostavu/app/actions/runs/42485640397) завершила публикацию и выкладку успешно. Работает green, предыдущий blue 0.1.0 остановлен и сохранён для отката.

## Автоматические проверки

- `npm run check`: Prettier, ESLint, FSD, TypeScript и 56 тестов прошли
- `npm run build`: созданы production-сборка, manifest и service worker
- [CI реализации](https://github.com/po-sostavu/app/actions/runs/42483185907): все восемь заданий прошли, включая Docker и изолированное переключение с откатом
- Независимое ревью выявило сохранение устаревшего положительного результата проверки установки. Свежий пустой ответ теперь снимает этот признак, сценарий покрыт тестом

## Браузер

Проверка выполнена в отдельном headless Chrome с временным профилем, без установки пакетов. Основной профиль пользователя не использовался. Ошибок выполнения JavaScript не обнаружено.

После выкладки 0.2.0 десять групп проверок повторены на публичном приложении 8 ноября в 13:56:51 UTC. Проверены ширина 320 px, область кнопки не меньше 44 × 44 px, фокус и Escape. Исключений JavaScript нет. Последующая HTTP-проверка в 13:57:33 UTC подтвердила HTTPS, точный SHA выпуска, готовность API, manifest и service worker.

| Сценарий | Результат |
| --- | --- |
| Ширина 320 px | Шапка и инструкция помещаются без горизонтальной прокрутки |
| Размер кнопки | Область нажатия не меньше 44 × 44 px |
| Диалог | Фокус находится внутри, Escape закрывает окно и возвращает фокус кнопке |

Геометрия, DOM, навигация, фокус и клавиатура проверены настоящим Chrome. Платформенные признаки, события установки и ответы проверки установленности эмулированы. Это подтверждает работу интерфейса с этими сигналами, но не заменяет установку средствами ОС на физическом iPhone, iPad, Android или Mac. Такие проверки в этот результат не входят.

## Совместимость

Идентификатор, стартовый адрес и scope manifest сохранены. Добавлена только ссылка на собственный webapp. Контракт API, БД, миграции, серверные секреты и политика кэша не меняются. Обновление уже установленной PWA остаётся действием пользователя.

Из обычной вкладки установленность определяется не во всех браузерах. Self-reference без абсолютного related id улучшает проверку на поддерживаемом Android, сохраняя переносимость сборки. На desktop и в Safari кнопка может оставаться видимой в обычной вкладке. Постоянный локальный флаг установки не используется.

Основания для браузерного поведения: [одноразовый prompt](https://developer.mozilla.org/en-US/docs/Web/API/BeforeInstallPromptEvent/prompt), [проверка связанной PWA](https://developer.chrome.com/docs/capabilities/get-installed-related-apps), [установка в Safari на Mac](https://support.apple.com/en-gb/104996).
