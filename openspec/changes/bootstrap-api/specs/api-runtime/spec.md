# Spec Delta

## Purpose

Технический API должен запускаться с проверенной конфигурацией, сообщать о доступности зависимостей и завершаться без бесконечного ожидания.

## ADDED Requirements

### Requirement: Проверка конфигурации при запуске

API MUST проверять обязательные параметры PostgreSQL, адрес сервера и конечные положительные ограничения ресурсов до приёма запросов. Ошибки конфигурации MUST NOT раскрывать значения секретов.

#### Scenario: Некорректное окружение
- **WHEN** обязательный параметр отсутствует либо тайм-аут или размер пула недопустим
- **THEN** процесс завершается с ненулевым кодом до открытия HTTP-порта и сообщает имя ошибочного параметра без его значения

### Requirement: Жизнь и готовность сервиса

API MUST предоставлять GET `/livez` и GET `/readyz`. Проверка жизни не зависит от PostgreSQL; готовность зависит от доступности PostgreSQL и имеет конечный тайм-аут.

#### Scenario: PostgreSQL доступна
- **WHEN** выполняется GET `/readyz` и проверка БД успешна
- **THEN** API возвращает HTTP 200 и JSON статуса готовности

#### Scenario: PostgreSQL перестала отвечать
- **WHEN** запрос к БД завершается ошибкой или истекает его тайм-аут
- **THEN** `/readyz` возвращает HTTP 503 с безопасной JSON-ошибкой, а `/livez` продолжает возвращать HTTP 200

### Requirement: Безопасный контракт ошибок

API MUST возвращать JSON-ошибки с машинным кодом, сообщением и request ID. Ответы и технические логи MUST NOT содержать DSN, пароль, SQL, тело пользовательского запроса или stack trace. Неизвестный маршрут MUST возвращать HTTP 404.

#### Scenario: Неизвестный маршрут
- **WHEN** клиент запрашивает отсутствующий endpoint
- **THEN** получает HTTP 404 с описанной в OpenAPI ошибкой и серверным request ID

### Requirement: Управляемое завершение

При сигнале остановки API MUST прекращать приём новых соединений, ограниченно ждать текущие запросы, отменять оставшиеся операции и закрывать ресурсы. Ошибка запуска listener MUST завершать процесс с ненулевым кодом.

#### Scenario: Остановка работающего API
- **WHEN** процесс получает SIGTERM либо прерывание консоли
- **THEN** остановка ограничена настроенным временем и пул БД закрывается после завершения запросов либо отмены их контекстов
