# Proposal

## Why

Каркасы PWA и Go API уже имеют локальные проверки и Dockerfile, но Pull Request не запускает их автоматически. Изменение реализует часть CI задачи [PRD-31](https://linear.app/po-sostavu/issue/PRD-31), чтобы дальнейшая разработка и подключение приложений опирались на воспроизводимые проверки.

## What Changes

- Добавить GitHub Actions для PR в `develop` и `main`, push в эти ветки и ручного запуска.
- Проверять PWA существующими npm-командами, Go API — командами Task, включая race detector и сборку.
- Проверять известные уязвимости npm- и Go-зависимостей с явной политикой завершения проверки.
- Собирать контейнеры PWA, API и миграций без публикации образов.
- Описать запуск, результаты, ограничения и дальнейшее подключение проверок к правилам слияния.

## Capabilities

### New Capabilities

- `continuous-integration`: воспроизводимые проверки изменений PWA, API и их контейнерной упаковки без доступа к рабочим секретам.

### Modified Capabilities

Нет.

## Impact

Затронуты `.github/workflows`, документация процесса и данный OpenSpec change. Используются существующие npm scripts, Taskfile и lock-файлы. Продуктовый код, зависимости приложений и HTTP-контракт не меняются. CD, публикация образов, тестовый сервер, общий шлюз, интеграция PWA с API, изменение GitHub branch protection и выпуск релиза не входят в задачу. PRD-31 целиком этим изменением не закрывается.
