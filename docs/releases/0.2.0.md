# Выпуск 0.2.0

8 ноября 2026 года опубликован и после подтверждения владельца развёрнут [релиз v0.2.0](https://github.com/po-sostavu/app/releases/tag/v0.2.0), коммит `5913cb2f3daff26ae2ded8c3580d51b3a4af5f5f`. На [posostavu.ivanzubkov.ru](https://posostavu.ivanzubkov.ru) работает комплект green. Предыдущий выпуск `0.1.0` сохранён для отката.

В шапке появилась кнопка установки PWA. Она открывает системное окно браузера или инструкцию для устройства и скрывается при подтверждённой установленности. В обычной вкладке не все браузеры позволяют определить установленность. Постоянный локальный флаг не используется. Новых npm-зависимостей нет, API, БД, миграции и политика кэша не меняются.

- `npm run check` и `npm run build` прошли, выполнены 56 тестов
- В Chrome проверены десять групп сценариев, ширина 320 px, диалог и клавиатура. Установка средствами ОС на физических устройствах не проверялась. Подробности — в [отчёте проверки](../../openspec/changes/install-pwa/verification.md)
- [CI коммита main](https://github.com/po-sostavu/app/actions/runs/42485198115) завершил все восемь заданий успешно
