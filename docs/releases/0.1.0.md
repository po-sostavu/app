## Данные и границы проверки

Стенд работает с `mode: test`, `enabled: true`, `recovery_verified: false`. Имя GitHub Environment `production` не меняет режим данных. Внешние резервные копии и пробное восстановление отложены владельцем. Перед запуском мигратора создана и проверена локальная копия в `/opt/po-sostavu/backups`. Прикладных SQL-миграций в этом выпуске нет.

После выкладки доступно около 1,76 ГиБ памяти и 15,3 ГиБ диска. Это замер первого запуска, перед следующим выпуском обработчик проверит ресурсы заново.

Первый выпуск не имеет предыдущей версии для отката на VPS: `previous` в состоянии равен null. Переключение между двумя цветами и возврат проверены изолированным Linux-тестом CI. Реальный откат на этом VPS пока не выполнялся. При следующем совместимом выпуске обработчик сохранит текущую версию как предыдущую. Откат приложения не откатывает БД.

Проверены доставка оболочки PWA, readiness и инфраструктура. Проверка установки PWA в браузере и продуктовых сценариев в этот результат не входит. Для рабочих пользовательских данных сначала нужны проверенное восстановление и переход в `mode: production` по [регламенту CD](../cd.md).
